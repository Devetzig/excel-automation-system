# Devetzis Electro Service - Management System
 

---

## 📂 Project Overview

This repository contains a complete **management system** for Devetzis Electro Service, including:

1. **Product Catalog**  
   - Excel sheet with all products, categories, unit prices, VAT, stock quantity, and reorder info.  
   - File: [Uploading DEVE_PRODUCT_CATALOG.xlsx…]()


2. **Order Management**  
   - Excel sheet tracking all orders, customers, quantities, discounts, VAT, total price, and delivery dates.  
   - File: [DEVE_ORDER_MANAGEMENT.xlsx](https://github.com/user-attachments/files/26189666/DEVE_ORDER_MANAGEMENT.xlsx)


3. **Reports**  
   - Sales summary including metrics: total orders, total revenue, total VAT, average, min/max orders.  
   - Top products and top customers tables.  
   - Payment method analysis.  
   - File: [DEVE_REPORTS.xlsx](https://github.com/user-attachments/files/26189668/DEVE_REPORTS.xlsx)


4. **Warranty Template**  
   - Word document providing 4-year mechanical warranty for delivered products.  
   - File: [DEVE_WARRANTY_DOC.docx](https://github.com/user-attachments/files/26189670/DEVE_WARRANTY_DOC.docx)

## 📝 Notes

- VAT is applied at 24% on all products.  
- Discounts are applied per order.  
- Warranty covers **mechanical parts only**, valid for 4 years.  
- Designed for small-to-medium automotive service business.
